# pimsim — PIM-SM 稀疏模式组播路由仿真

面向省级应急广播传输网场景:几百个接收点经专网收省台组播节目流。
用 Go 实现了稀疏模式组播路由协议(PIM-SM 风格)+ 离散事件仿真网络,
替代全网泛洪,解决"没人收的支线也在跑流量"和"换路由断流"问题。

## 运行

```bash
go run . -mode test          # 跑全部验收场景
go test ./...                # 同上,以单测形式
go run . -mode web           # 启动可视化页面 http://localhost:8080
```

## 协议实现(router.go)

1. **邻居与 DR**:周期 Hello(4s)维持邻居,按(优先级, ID)选出网段 DR,
   由 DR 替本网段接收者(IGMP Report)往上游发 (*,G) Join。
2. **共享树**:Join/Prune 沿 RPF(RP) 逐跳上送;上游状态靠下游周期刷新(8s)
   保持,3 倍周期不刷新即超时拆除;接收者离开立即向上 Prune。
3. **源注册**:第一跳 DR 把数据封装成 Register 单播给 RP;RP 有接收者就解封
   转发并沿 (S,G) 反向建树,收到原生数据后回 Register-Stop 压停注册。
4. **SPT 切换**:最后一跳按包数门限(默认 8)切到 RPF(S) 方向的最短路径树,
   同时在共享树上对该 (S,G) 发 RPT 剪枝。切换期两棵树并存,路由器级去重,
   保证接收者不丢包、不收双份。
5. **断言 Assert**:同一网段多台路由器要往下转同一流时,按(是否有 (S,G)
   状态, 到源/RP 度量, ID)选唯一赢家;多接入网段上新增 (S,G) 出接口前先发
   断言探针、延迟开闸,把瞬态双份也消掉。
6. **RPF 检查与跟随**:数据/加入报文都做反向路径检查;单播(全源 Dijkstra
   最短路)一变,所有组播状态立即刷新 RPF——旧邻居发 Prune、新邻居发 Join,
   树跟着改道。

## 仿真拓扑(network.go)

R1–R2–R3–R4–R5–R1 成环 + R2–R4 斜拉(多路径);lanM(R4/R5/R8+主机 H10)、
lanA(R3/R6/R7)两个多接入网段;源 S1 在 R1 后,RP 在 R2,接收者 H4/H6/H7/H8/H10。

## 验收场景(scenarios.go)

| 场景 | 验收点 |
|---|---|
| join-leave | 共享树随加入/离开生长、拆除;非 DR 不建状态 |
| source-start-stop | Register/Register-Stop;源停后 (S,G) 超时拆、(*,G) 保留 |
| spt-switch | 切换全程 0 丢 0 重;无人接收链路(c34/c45/c24)无该流流量 |
| link-fail | 断 c23 后树按新最短路重建,转发表与应有树一致,恢复后切回 |
| assert-lan | lanM 上 Assert 选出唯一转发者,接收者 0 丢 0 重 |

每个场景结束都逐台路由器对比实际出接口表 vs 按拓扑最短路算出的应有的树,
并统计每个接收者的丢包/重复、每个网段上该流的实际流量。

## 可视化(web.go + web/index.html)

`go run . -mode web` 后打开页面:左侧 SVG 拓扑(绿线=当前有流量的网段,
蓝虚线=(*,G) 共享树边,绿实线=(S,G) SPT 边,金圈=RP);右侧可让接收者
加入/离开、源启停、断/通任意链路,实时看每台路由器的 (*,G)/(S,G) 状态项
(IIF/OIF/SPT 标志)和每个接收者的收/丢/重统计。仿真按 5 倍速推进。
